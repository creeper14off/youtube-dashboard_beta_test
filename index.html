Comment obtenir votre clé API YouTube ?

Suivez ces 4 étapes simples et 100% gratuites :

1

Étape 1 : Créer un projet Google Cloud

Rendez-vous sur la console Google Cloud :

open_in_new console.cloud.google.com

Connectez-vous avec votre compte Google et cliquez sur 'Nouveau projet' (nommez-le par exemple 'Mon YouTube Dashboard').

2

Étape 2 : Activer la bibliothèque YouTube API

Dans le menu à gauche, allez dans API et services > Bibliothèque. Recherchez YouTube Data API v3 et cliquez sur Activer.

3

Étape 3 : Créer votre clé API

Allez dans API et services > Identifiants. Cliquez sur + Créer des identifiants en haut, puis sélectionnez Clé API. Copiez la clé qui commence par AIza....

4

Étape 4 : Trouver l'ID de votre chaîne

Allez sur studio.youtube.com, cliquez sur Paramètres > Chaîne > Paramètres avancés (ou youtube.com/account_advanced). Copiez l'Identifiant de chaîne (commence par UC...). Vous pouvez aussi simplement utiliser votre identifiant avec @ (ex: @machaîne) !

🔒 Sécurité locale : Vos identifiants restent stockés exclusivement dans votre navigateur local. Aucune donnée n'est transmise à un serveur tiers.
